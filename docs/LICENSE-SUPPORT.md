## 正常激活与恢复

1. 在插件“授权与支持”中查看状态。尚未购买时，可以按产品规则主动开启试用或联系作者购买。
2. 粘贴完整授权码，确认来自作者并用于当前设备。不要把授权码、设备申请码或私人笔记贴到公开问题中。
3. 换机、清空应用存储或部分重装后，若提示设备不匹配，通过授权页提供的联系方式联系作者，私下提交本机申请码申请核对或重新签发。
4. 遇到存储占用提示，关闭重复的应用窗口并重启 Obsidian 后重试。其他问题记录插件版本、Obsidian 版本、操作系统、错误原文和复现步骤；不要通过清空应用数据、删除授权记录或改动系统时间来尝试修复。
5. 排查前备份相关用户内容与设置。开发者应修复读取、兼容性或错误处理问题，保留授权验证及离线能力；无有效授权时，免费功能与已保存内容仍应可用。

作者联系方式见插件授权页及 [README](../README.md)。一般故障可通过 [GitHub Issues](https://github.com/Tangerine-Cat888/zhaohua-xishi/issues) 报告。涉及可复用的解锁方法、真实凭据或私人数据时，先通过授权页的作者联系方式私下报告；隔离环境的最小复现应使用测试数据，不附带可直接分发的解锁包。
