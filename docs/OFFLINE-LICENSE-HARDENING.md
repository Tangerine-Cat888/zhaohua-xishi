# 离线授权加固

2026-11-11，本次为本地源码改动，未制作安装包、安装到日常笔记库或发布。

## 改动与兼容

- 授权状态、试用状态和存储引用改为 JavaScript 私有字段；对外仅提供只读状态，已验证的授权和试用快照冻结。
- 授权实例和原型冻结，插件加载时固定授权服务及关键权限检查方法，阻止常见的运行时赋值、getter 覆盖和服务替换。
- 在原本机 IndexedDB 中增加 `trial-seal-v1`。签名绑定产品、设备、开始及结束时间；签名校验失败时不授予试用权益。设备密钥仍不可通过 Web Crypto 导出。
- 原 `trial` 记录保留。首次读取旧记录时补签，开始和到期时间保持不变；永久授权的格式、公钥、存储位置不变，无须重新发码。
- 图片真正写入前再次校验权限，覆盖等待保存路径期间试用到期的情况。到期后仍允许保存排版状态。
- 不增加联网验证、周期性联网、遥测、第三方依赖或硬件指纹。不修改免费回顾、感想和用户笔记。

## 防护边界

这是针对直接修改运行时状态和本地试用日期的加固，不是防破解保证。客户端文件、系统时间和完整应用存储均由用户控制。攻击者修改整个 JavaScript 文件、替换更多调用路径或恢复旧应用环境，仍可能绕过。具备同进程代码执行能力的攻击者也可能调用本机设备密钥签名；不可导出不等于不可使用。

为兼容旧版无签名记录，首次迁移只能信任原记录；同时移除试用和签名记录、完整重置存储或回滚旧版本仍无法可靠阻止。未加入系统时钟回拨封禁，避免正常校时误伤；试用继续依赖本机时间。永久会员不受试用记录异常影响。

签名校验发生在初始化和主动开始试用时，日常权限读取仍为内存检查。不进行每次界面刷新时的磁盘或密码学运算。
