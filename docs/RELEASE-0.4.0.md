## 安装与升级

市场安装后，首次导出请点击下载约 53 MB 的字体和图库，之后可离线使用；下载不会发送笔记或授权信息。程序随 main.js 安装，资源包不含执行代码。

离线安装可下载 **zhaohua-xishi-0.4.0.zip**，解压后将 zhaohua-xishi 文件夹合并到笔记库的 .obsidian/plugins/。升级请保留 data.json、export-photos/ 和 export-fonts/。
