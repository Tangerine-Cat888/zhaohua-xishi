# 0.4.2 · 把喜欢的排版存成模板

- 内置模板和自己的模板放在同一个列表里，选中即可使用。
- 通过“另存为模板”保存字体、纸色、配图与裁切，不保存正文或署名。
- 设置中新增模板管理：复制新建、编辑、排序、移除和恢复。彻底删除会再次确认，导入的照片和字体保留。
- 旧“我的样式”继续可用，重新打开导出窗口也会保留上次的临时调整。
- 优化图库浏览、纸墨搭配和小猫预览，修复弹出窗口中的链接与焦点判断，并更新开发检查依赖。

会员权益、72 小时体验及早鸟日期不变；已有永久会员无需补差价或重新激活。

## 安装与升级

市场安装后，首次导出请点击下载约 53 MB 的字体和图库，之后离线使用。已有完整资源可以继续使用；下载包只包含静态资源，程序随 main.js 安装。

离线安装下载 **zhaohua-xishi-0.4.2.zip**，将其中的 zhaohua-xishi 文件夹合并到笔记库的 .obsidian/plugins/。升级时保留 data.json、export-photos/ 和 export-fonts/。

GitHub 发布和 Obsidian 审核是不同状态，市场更新以官方页面为准。项目继续使用原有自定义许可。
