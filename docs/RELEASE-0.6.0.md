# 0.6.0 · 公众号排版

现在可以在 Obsidian 里整理一篇笔记的公开版本，预览调整后复制到公众号后台。

- 三款模板，支持正文、标题、局部字色和整篇配色调整。
- 临时删改不影响原笔记；库内图片自动读取并嵌入。
- 复制富文本或保存 HTML；模板和配色可以保存、编辑、排序及恢复。
- 图片模板编辑改为双栏预览，独立设置窗口关闭编辑后恢复尺寸和位置。

包含在已有永久会员和有效试用中，不改变已开始的试用或早鸟截止时间。

市场安装 main.js、manifest.json、styles.css。图片导出首次需主动下载字体图库，之后可离线使用；公众号排版程序随插件安装。也可使用完整离线 ZIP。升级保留 data.json、export-photos/ 和 export-fonts/。

公众号后台可能调整粘贴样式或图片，粘贴后请检查；本插件不自动发布文章。Windows 桌面已验收，手机真机与最低 Obsidian 1.7.2 未实测。
