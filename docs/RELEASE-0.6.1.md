# 0.6.1 · 保存规则与模板管理

- 公众号 HTML 可独立选择保存目录，按标题、日期或自定义格式命名；同名自动编号，不覆盖已有文件。
- 修复公众号“另存为模板”点击无响应，以及中文输入法选字误触保存。
- 图片与公众号模板编辑保存成功后关闭，失败保留输入；复制自动处理长名称与重名。
- 已移除的公众号模板、配色支持确认后彻底删除；删空后仍可新建。删除确认保留列表版本，防止陈旧窗口误操作。

会员、早鸟和已有试用期限不变。升级保留 data.json、export-photos/、export-fonts/。市场自动安装 main.js、manifest.json、styles.css；图片导出资源首次按需下载，已有完整资源可直接复用。额外 ZIP 不由市场自动安装，完整离线包可手动合并安装。

Windows 桌面验收；未实测手机真机、最低 Obsidian 1.7.2 或公众号后台粘贴。
