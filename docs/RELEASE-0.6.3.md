# 0.6.3 · 公众号文章也能导出长图和卡片

在公众号排版窗口点击「导出分享」，可以保存 HTML、长图，或 3:4 / 9:16 图文卡片。先预览、翻页检查，再确认保存；多张卡片自动打包 ZIP。

沿用公众号导出目录和命名规则，同名自动编号。缺图、网络图片跨域限制或超高内容会明确提示；导出不修改原笔记。修复了分页末尾极小余量被误判为内容过高的问题。

会员、已开始的试用和早鸟时间不变。升级保留 data.json、export-photos/、export-fonts/。市场安装三个文件；四款图片模板的字体图库首次按需下载，之后可离线使用。公众号长图和卡片无需下载该图库。完整离线 ZIP 可手动合并安装，市场不会自动下载额外 ZIP。

已在 Windows Obsidian 1.15.0 验收；手机真机及最低 Obsidian 1.7.2 未实测。
