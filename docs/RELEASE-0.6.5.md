# 0.6.5 · 标注块也能一起导出

图片导出和公众号排版支持 Obsidian 标注块，保留标题、列表、图片与嵌套；折叠正文在导出时完整展开。

配色可选“随排版配色”或“按标注类型配色”，支持 13 类内置类型与别名，并随个人模板保存。旧模板默认沿用排版配色。

短标注尽量整块分页，长文字标注允许跨页，标题不单独留在页尾。可编辑的图片画布标注改字后保留语法；复杂块请在原稿区修改。

会员、已有试用和早鸟时间不变。升级保留 data.json、export-photos/、export-fonts/。首次使用四款图片模板需主动下载字体图库，之后可离线使用；完整离线 ZIP 需手动安装，市场不会自动下载额外 ZIP。

Windows Obsidian 1.15.0 实测；手机真机与最低 Obsidian 1.7.2 未实测。
