# 0.7.0 · 新版书架与照片墙

在弧形书架上左右翻动封面，或者点书名找书。打开一本书，照片、短笺和文字摘录就排在一起。点卡片读原文、写感想，按 Esc 就回到原处。可以拖动画布，按 Ctrl 滚动缩放，切换空白、点阵或方格背景。

永久会员 39.9 元，一次购买。已有永久授权继续有效，已开始的旧体验按原时间到期。随机回顾、往年今日和保存感想免费。

- 市场安装或更新使用 main.js、manifest.json 和 styles.css。首次使用图片导出时可按提示下载字体和图库。
- 完整离线包内已包含资源。手动升级请保留 data.json、export-fonts/ 和 export-photos/。
