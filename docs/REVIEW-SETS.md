# 多个回顾集

设置 → 朝花夕拾 → 回顾集 → 管理回顾集，可添加、编辑、移除分类。

- 默认「日记」沿用原目录、日期格式和是否包含子文件夹；原封面、草稿、回顾记录保持兼容。
- 新回顾集指定名称和来源目录，默认不要求日期。每个回顾集可选 title 属性、正文第一个标题或文件名作为标题；所选内容为空时只回退到文件名。
- 日期可选择不使用、从文件名识别或读取指定属性。属性日期按设定格式解析；缺失或无效仍可随机回顾，但不参与往年今日。不使用文件创建/修改时间兜底。
- 文件名日期模式保留日记规则：只收录日期有效且早于今天的文件。
- 有额外回顾集才显示标题切换入口；随机回顾、往年今日和书架同步选择，不提供「全部内容」。无日期模式隐藏往年今日入口。
- 回顾导航按回顾集独立保存；冷却与感想草稿按文件路径共享，避免重叠目录中重复抽到。
- 感想统一保存到现有今日日记配置，仍支持模板和原文链接。暂无按回顾集设置不同感想目标。
- 我的书架点击纯文字标题切换分类。每个回顾集可选择按月份或按子文件夹成书，独立保存封面、书名、篇目排除和阅读位置。原日记本默认按月，旧配置原样保留。按月只收入日期有效且早于今天的记录。
- 移除分类不删除原文件。分类配置采用稳定 ID，改名不影响导航。

回顾集管理与随机回顾向免费用户开放，书架成书阅读需要永久会员授权。

## 按子文件夹成书

管理回顾集 → 编辑 → 成书方式 → 按子文件夹。默认日记来源在插件设置的“默认日记本成书方式”中调整。

每个直属子文件夹生成一本书，包含所有更深层 Markdown 笔记；根层笔记不成书，无内容的文件夹不显示。书名默认使用文件夹名，可编辑封面书名。篇目按文件名自然排序（2 在 10 前），同名再按路径排序。没有日期也能收入；目录和阅读页使用该回顾集选定的标题来源。

隐藏年份筛选、阅读日期、日期目录编号和“本月”措辞；页码使用“第 1 / 3 篇”。感想仍可保存到今天日记。随机回顾的递归和日期设置不受成书方式影响。按月与文件夹书籍使用不同标识，切换模式不覆盖已有封面和进度。

## 设置页

设置按回顾内容、我的日记本、感想保存、授权与支持分组。新版 Obsidian 使用原生分组定义，旧版沿用兼容渲染；保留“日记模板”名称与应用按钮。选中默认日记时，书架标题为“我的日记本”。
