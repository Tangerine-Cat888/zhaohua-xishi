# 公众号排版

已接入插件，使用与图片导出相同的现有会员权限。

## 入口

- 命令面板：朝花夕拾 → 公众号排版。
- 编辑器右键：全文或选中文字排版到公众号。
- Markdown 文件右键、回顾页、书架阅读工具栏：公众号排版。

优先读取当前编辑器内容（包括未保存修改）；有选区时只带入选区。原稿区只做临时编辑，不修改原笔记、不创建笔记副本。关闭后正文与局部字色不保留。

## 图片与输出

库内 Markdown 图片、双链图片按来源笔记解析为内嵌图片。仅支持 PNG、JPEG、WebP、GIF，单图上限 20 MB。缺图或读取失败时阻止复制与导出，修正后可重试。网络图片保持原 URL。

「复制排版」写入 HTML 和纯文本两种剪贴板格式；公众号后台实际粘贴效果仍须在后台验收。
「导出 HTML」默认保存到当前笔记的 Obsidian 附件位置，也可在设置的「公众号导出保存规则」中指定库内目录（自动创建）。命名可选标题、日期加标题或自定义格式，支持 {title}、{date}。日期优先使用 date 属性，再识别日记文件名，最后回退今天；同名自动编号，不覆盖已有文件。此设置独立于图片导出。

排版偏好、个人模板及明确启用/保存的固定结尾存入当前库插件 data.json；不使用共享浏览器存储保存笔记。独立原型仍使用自身浏览器存储。

## 开发验证

`scripts/build-wechat-studio.mjs` 把工作台脚本、样式和静态 HTML 内嵌到插件，无需运行本地服务器或下载执行代码。iframe 使用独立来源沙箱，宿主消息校验窗口来源、会话与参数。读取原稿和图片、复制及导出均验证现有权限。

`npm run lint` 包含工作台 JavaScript 语法、DOM、安全与界面样式检查；`npm run check` 包含构建、宿主桥接测试和工作台模型测试。浏览器排版测试位于 `prototype/wechat-studio/tests/features-browser.html`。

0.6.0 发布验收记录在 `work/release-0.6.0-verification.md`；历史开发验收见 `work/wechat-integration-20261112/`。

## 标题层级

默认自动识别正文实际存在的最高两级标题（排除作为文章标题的 H1），分别应用章节和小标题样式。例如只有 H3 时，H3 使用章节样式；新增 H2 后，H2 使用章节样式、H3 使用小标题样式。可以切换「按原始层级」恢复 H2/H3 的固定对应关系。原稿和输出 HTML 的原始标题标签不改写，只调整排版样式。

无正文 H1 的笔记开启「显示文章标题」后，使用 title 属性或文件名补充显示，不插入原稿。固定结尾不参与正文层级的识别。


## 插件设置中的配色和模板
设置现在分为「图片导出」与「公众号排版」。公众号排版下的配色方案和模板管理支持复制新建、编辑、排序、移除与恢复；已移除项目可确认后彻底删除，删空后仍可新建。编辑成功保存后关闭，失败保留输入。编辑窗口用固定内容实时预览，保存不包含正文、图片、署名或固定结尾。内置项目通过复制编辑，自建模板保留完整配色快照。

公众号库存储在 wechatStorage 的 zhaohua-wechat-library-v1，旧 zhaohua-wechat-styles-v1 在首次库操作时兼容迁入，原记录保留。库写入带修订检查与失败回滚，避免陈旧窗口覆盖。设置编辑不保存日常排版偏好。独立设置窗口的 iframe 响应通过会话令牌与未完成请求标识建立可信响应窗口，再固定来源检查；请求仍验证 iframe 来源和会话。
